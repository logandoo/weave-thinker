# web_search — 联网搜索

## 适用场景
- 时效性信息（新闻、价格、发布日期、热点事件、当下日期相关）
- 你不确定的事实、具体的数字/数据
- 你知识截止之后的事件
- 用户明确要求查证或对比的信息

## 用法
调用 `web_search(queries=[...])`，传入关键词列表。

## 规则
1. 对于任何任务，最多进行 **3 轮搜索**，每轮最多 **3 个关键词**。
2. 搜索后如果结果不够充分，可以换关键词再次搜索，或用 `browser` 工具浏览具体网页深入获取。
3. 优先使用 `browser` 深入浏览已找到的关键网页，而不是不断换关键词搜索。
4. 引用格式：基于搜索结果回答时，必须在正文中使用角标 `[1]`、`[2]` 标注所使用的检索结果序号，序号与搜索结果编号严格对应。每个事实陈述后紧跟对应的 `[N]` 标记。
5. 禁止在回答末尾添加"参考资料""参考文献"等章节——引用信息仅通过正文中的 `[N]` 角标标注，系统会自动在回答下方以标签形式展示引用来源。
6. 当没有调用 web_search 时，禁止自行编造引用来源或添加任何参考章节。
7. 不要输出"我来搜索...""我先查一下..."等准备性语句就结束回答——需要搜索就立即调用 web_search。
