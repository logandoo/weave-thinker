BACKEND_DESIGN — workspace 原语（内部 agent 工具面）

本设计不新增 HTTP 端点；交付物为工具 schema + 服务接口 + 配置键。HTTP 面仅 GET /api/system/capabilities（现有）会列出新工具。

1. 模块与接口

模块接口（Produces）
app/services/workspace_file_state.py read_tracker.record_read(user_id, path, mtime_ns, size) · read_tracker.check(user_id, path, mtime_ns, size) -> str|None · read_tracker.forget(user_id, path)（容量 1024 FIFO）
app/services/workspace_snapshot_service.py async create_snapshot(user_id, workspace_path, reason="") -> dict · async list_snapshots(user_id, workspace_path, limit=20) -> dict · async restore_snapshot(user_id, workspace_path, snapshot_id) -> dict
app/services/process_session_service.py process_manager.start/write/read/kill/list/shutdown_all（async，除 list）
app/tools/workspace_write.py 注册 workspace_write · workspace_edit（toolset files）
app/tools/workspace_snapshot.py 注册 workspace_snapshot（toolset files；restore 自门控 workspace_restore）
app/tools/process_tool.py 注册 process（toolset system；start/write/kill 自门控 terminal_execution）

2. 工具 schema（节选）

workspace_write { path*, content*, mode: overwrite|append|create_only }
  → { success, path, created, bytes_written, lines, diff_summary, diff, snapshot_id|snapshot_error }
workspace_edit  { path*, old_string*, new_string*, replace_all? }
  → { success, replacements, diff_summary, diff, snapshot_id|snapshot_error } | { error, count }
workspace_snapshot { action*: create|list|restore, snapshot_id?, label? }
  → create: { success, snapshot_id, created_at }
  → list:   { success, snapshots:[{snapshot_id, created_at, reason}] }
  → restore:{ success, restored_files, newer_files_kept, snapshot_id }
process { action*: start|write|read|kill|list, session_id?, command?, cwd?, data?, newline?,
          wait_ms?, max_chars? }
  → start: { success, session_id, pid, cwd, output, cursor }
  → read:  { success, stdout, stderr, cursor, running, exit_code, dropped_bytes }
  → 其他:  { success, ... }

3. 配置键（config.toml，行为配置）

[workspace]
snapshots_enabled = true
snapshots_max_file_mb = 10
snapshots_retention = 50

[agent.process]
max_sessions_per_user = 4
idle_timeout_seconds = 1800
max_buffer_bytes = 262144
max_read_chars = 20000

properties：config.workspace_snapshots_enabled / ..._max_file_mb / ..._retention · config.agent_process_max_sessions / ..._idle_timeout_seconds / ..._max_buffer_bytes / ..._max_read_chars。 全部有代码默认值——60 远端 config.toml 不被部署覆盖，缺键即默认行为，无需远端改配置。

4. 权限与可观测性

  • agent_permissions.DEFAULT_AGENT_PERMISSIONS：workspace_write=True · workspace_restore=False；permission_key_for_tool_request("process", {action}) → terminal_execution（start/write/kill）。
  • registry 超时：现有 agent_tool_loop_tool_call_timeout 覆盖全部新工具（进程 read 的 wait_ms 上限 30s，远小于工具超时）。
  • 工具结果预算：write/edit/snapshot 加入 tool_result_budget._UNLIMITED_TOOLS（小结果）。

5. 非目标

  • PTY/终端渲染（本版管道；依赖 TTY 的程序输出可能不完整，文档说明）。
  • 跨服务重启的会话持久化。
  • apply_patch freeform 语法（模型无关 edit 已覆盖；后续可按模型切换）。
  • UI 变更（无前端改动）。
