1. 权威与所有权

Python 唯一权威：产品 gate/audit/security/taint/approval/deathmatch。
OpenCode 适配器：开发 harness 的 tool/context/compaction hooks。
每个会话：一个 compactor、一个 pendingResume writer、一个 continuation scheduler。恢复上下文绝不回滚工作区，也不提升信任或授权。

2. OpenCode v1/v2 数据流

tests/working_note.md → memory-snapshot.json → compactStateBundle(root)
v1: experimental.session.compacting → output.context
v2: ctx.session.hook("compaction") → event.system[{type:"text",text}]
       ↓ actual compactor input（不是仅消息存储）
compaction succeeds
v1: session.compacted
v2: session.compaction.ended
       ↓ mark delivery-state.json pendingResume[exact sessionID]
next primary request
v1: experimental.chat.system.transform
v2: ctx.session.hook("context")
       ↓ one logical restore; re-arm only on a later compaction

独立 `opencode run` 进程验证恢复不依赖内存。恢复前不得禁用宿主 continuation；没有第二自动续跑调度器。v2 `event.result` 不由本插件设置，避免成为第二 compactor。

3. Python 产品数据流

ContextCompressor pre-summary → prepare/attach delivery bundle
  → summary + synthetic resume + persistent pendingResume
  → chat_stream_transport 下轮精确 conversation 消费
DeathmatchPlanCoreMixin → 同一 delivery_root / delivery_conv_id / delivery_active

现有 DB rolling summary/artifact/resume snapshot 保持权威；working note 是任务态，不与 DB 记忆合并成第二套账。最新用户消息逐字、证据三件套、provenance/taint 和 deathmatch 生命周期不被 prose summary 替代。

4. Checker 与状态安全

  • bundled checker 与 pin 同步；已有自定义 checker 不覆盖，hash 不匹配时执行 bundled canonical fallback。
  • assert 使用 JSON severity；输出畸形/超时/缺失不能变绿。
  • cue 有长度、星号和时间预算；观测命令有界；状态写前脱敏且保留未知字段。
  • silent-stop 只在非证据写入、任务活跃、无 final-run、无白名单时触发。

5. 同步与回滚

scripts/sync_opencode_vibeweaver.sh 默认只检查；--apply 先在用户配置目录创建时间戳备份，再同步插件和技能，最后逐文件 hash 校验。回滚即恢复备份；不改全局其他插件，不移除项目外功能。

6. 非运行时装载项

上游 installer/release/eval lab 不进入产品 runtime；它们在上游自检中使用。core profile 随包但不自动激活，D9 与 full force-inject 不变。风险/破坏命令审批继续由 act_gate/permission/git 白名单单一承载。

7. 边界与验证

真实 v2 以本地 fake provider 捕获 compactor 与 primary 请求，跨三个进程证明 pendingResume；mock 只用于形状负例。另跑上游 selftests、Python 定向回归、完整 CI parity、script build、双对抗评审和 fresh-context verify。任何不能真实验证的项目列入 Coverage unchecked，不伪装完成。
