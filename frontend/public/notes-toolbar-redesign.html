让格式在软件之间保持语义

笔记需要保留的是标题、强调、列表、表格和公式，而不是来源软件附带的私有样式。复制与粘贴都应先经过同一套内容契约。

本次改造的三个判断

  1. 横向滚动能解决“找得到”，不能解决“看得懂”。
  2. Word 的编号外观不等于真实列表；结构必须先被识别。
  3. 复制到外部软件时，同时提供 text/html 和 text/plain。

行内公式保留为 $E=mc^2$；Mermaid 保留完整换行，而不是把源码压成一行。

同一份内容，两种明确选择

默认保留结构，不让来源软件的视觉样式成为笔记的永久负担；需要时一键改为纯文本。向外复制时同时写入 HTML 与纯文本，由接收方选择它能理解的表示。

26 个现有动作归位

一级顺序固定为：正文、黑体、斜体、字符、段落、编辑、列表、插入、目录、语音输入（语音仅图标）。「链接」按用户要求放入「插入」菜单；所有二级菜单都使用「图标 + 文字」，只列动作，不再嵌套标签页或三级菜单。

现有动作新位置呈现与理由
粗体 / 斜体一级「黑体」「斜体」（正文右侧）保留即时状态；图标 + 文字，支持快捷键与 aria-pressed。
标题一级「正文」菜单正文、H1–H4 同一入口，显示当前块类型。
项目符号 / 编号 / 重新编号一级「列表」菜单列表创建与编号维护不再拆成三个图标。
表格 / 公式 / 代码块一级「插入」菜单文字名称 + 简短说明，减少符号猜测。
图片 / 音频 / 视频一级「插入」菜单同属外部内容插入，按媒体类型分组。
链接一级「插入」菜单既有 Ctrl/Cmd+K 能力的可见入口；不占一级格式位。
引用一级「段落」菜单直接动作，二级菜单内不再嵌套标签页。
左 / 中 / 右对齐一级「段落」菜单同组三选一，保留当前对齐状态。
高亮 / 字体颜色一级「字符」菜单打开原有颜色选择器，不再并列两个 A。
上标 / 下标一级「字符」菜单保留成对关系与状态。
清除格式一级「字符」菜单文字说明作用范围；整篇仍需确认。
尾注（启用时）一级「插入」菜单只在偏好开启时出现，避免隐形丢功能。
查找 / 查找替换一级「编辑」菜单合并为一个入口，二级菜单内切换替换。
目录一级「目录」按钮（语音左侧）用户要求提为一级；再次点击收起。
语音输入一级「语音输入」按钮独立一级入口，仅图标；录音中切换停止图标与状态。
字数统计工具栏右侧固定按钮保留原弹层与位置。
保存 / 导出 / 删除文档动作区与文本格式分离；窄屏导出收进文档菜单，删除始终需确认。
